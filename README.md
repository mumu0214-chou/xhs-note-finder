# xhs-note-finder

查找和筛选小红书对标笔记的 Codex Skill，包含检索指南、随技能携带的商家口吻参照、台账说明和台账脚本。风格参照位于 `references/style-baseline.md`，不含固定商品参数，单独安装本技能即可读取。

默认共用台账位于本机 `~/Documents/Codex/小红书笔记台账`。没有历史目录时可使用随包参照并从空台账开始；本机完整历史稿和较新反馈作为补充。需要延续已使用笔记的去重与反馈记录时，再迁移旧台账或指定其目录。个人历史台账不包含在本仓库中。

技能文件位于 `skills/xhs-note-finder`。安装时可请求 Codex 使用 `$skill-installer` 从本仓库安装该目录。私有仓库需要访问权限。
